# H1 — Shaping beats information

**Status: OPEN.** Test: the C vs F comparison, ../../docs/eval-protocol.md.

A brief shaped for its recipient produces better outcomes than the *same information* rendered in a
fixed generic template.

**Killed by:** F ≈ C. If a fixed rich template does as well, Bliss Point is one template plus a
linter — a smaller, more honest project (eval-protocol.md §9).

**Not to be confused with** "structure beats a one-line prompt", which is already known and is what
arm R measures. The whole design of arm F exists to stop that confound being sold as this result.
