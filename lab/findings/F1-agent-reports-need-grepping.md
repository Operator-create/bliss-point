# F1 — A confident FACT tag is not evidence

**2026-08-19.** Method note, learned the expensive way, twice in two days.

An agent investigation returned a technique table with file paths and a uniform "100% confidence"
column. Every path checked out. One number did not: a "120× cost reduction ($0.0035/M vs
$0.435–$1.32/M)" tagged FACT returns **no match** for any of those figures anywhere in the dsh tree.

**Second instance, same week:** a reply written to the expected file path, in the expected format,
with file:line citations and explicit unverified flags — and it was an audit of a *different
project entirely*, because the receiving pane had other work queued. Every quality signal was
present. The answer was to a question nobody asked.

**Conclusion:** output-quality signals do not detect either fabrication or misrouting. Only checking
against the source does. This is the argument for the eval protocol scoring 16 of 20 tasks
mechanically and letting judgement touch as little as possible — and for the linter checking
*inputs* rather than grading outputs.
